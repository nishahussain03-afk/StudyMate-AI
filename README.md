# 🤖 StudyMate AI

### Your Intelligent Student Assistant

StudyMate AI is an AI-powered student assistant designed to help college students with learning, programming, Artificial Intelligence, Machine Learning, DBMS, Data Science, project guidance, and interview preparation.

The application provides an interactive chatbot interface where students can ask questions and receive AI-generated responses using a pretrained Hugging Face language model.

---

## 📌 Project Overview

Students often need quick explanations, programming guidance, project ideas, and learning support while studying.

StudyMate AI provides a simple and interactive platform where students can communicate with an AI assistant through a conversational interface.

The application is built using **Python**, **Streamlit**, **Hugging Face Transformers**, and **PyTorch**, with the **SmolLM2-360M-Instruct** model used for generating responses.

### 🎯 Main Objective

The main objective of StudyMate AI is to create an accessible AI-powered learning assistant that can:

- Answer student questions
- Explain technical concepts
- Provide programming guidance
- Assist with academic subjects
- Support project development
- Help with interview preparation
- Maintain conversational chat history

# ✨ Features

## 🤖 AI-Powered Chatbot

Students can interact with StudyMate AI using natural language and receive AI-generated responses.

## 📚 Learning Assistance

The chatbot can help explain academic and technical concepts in simple language.

## 💻 Programming Support

Students can ask questions related to programming languages such as:

- Python
- Java
- Programming fundamentals
- Object-Oriented Programming
- Algorithms

## 🧠 AI & Machine Learning

The assistant can provide explanations related to:

- Artificial Intelligence
- Machine Learning
- Neural Networks
- Natural Language Processing
- AI models

## 🗄️ DBMS Assistance

Students can ask questions about:

- Database Management Systems
- SQL
- Normalization
- Keys
- Tables
- Database concepts

## 📊 Data Science Support

The chatbot can provide guidance related to:

- Data analysis
- Data visualization
- Machine learning concepts
- Data science fundamentals

## 💡 Project Guidance

StudyMate AI can help students understand project concepts, generate ideas, and provide development guidance.

## 🎯 Interview Preparation

Students can use the assistant to practice technical concepts and prepare for interviews.

## 💬 Chat History

Conversation messages are maintained during the current session, allowing students to continue their discussion naturally.

## 🗑️ Clear Chat

Users can clear the current conversation using the **Clear Chat** button.

## 🎨 Interactive User Interface

The application provides a clean and student-friendly interface using Streamlit.
